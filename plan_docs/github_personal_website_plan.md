# GitHub 个人网站内容规划（基于当前资料）

## 目标定位

打造一个「学术 + 工程并重」的个人主页，让招聘方在 30 秒内快速了解：

- 你是谁（研究/求职方向）
- 你擅长解决什么问题（技术栈与方法论）
- 你做过哪些可量化、可落地的项目（结果导向）

---

## 建议包含的核心模块（按优先级）

### 1) 首页 Hero（首屏）

- 姓名 + 当前身份（如硕士/实习经历/研究方向）
- 一句个人定位（示例：机器人运动控制与强化学习方向）
- 关键技术标签（ROS2 / MPC / PPO / Isaac Gym / sim2real）
- 入口按钮：`View Projects`、`Download Resume`、`Contact`

### 2) About（个人简介）

- 2-4 段简洁介绍：
  - 研究兴趣：具身智能、运动控制、强化学习、灵巧操作
  - 工程导向：从建模、算法设计到仿真验证与落地
  - 个人优势：理论基础 + 实践落地能力

### 3) Skills（技能图谱）

- **控制理论**：运动学/动力学、非线性控制、自适应控制、李雅普诺夫稳定性
- **算法能力**：PPO、DQN、DDPG、SAC、力位混合控制、扰动观测
- **工程与系统**：ROS2、Gazebo、Isaac Gym、MATLAB/Simulink、TCP/CAN
- **编程语言**：C++、Python

### 4) Projects（重点项目，最重要）

每个项目建议统一为如下结构：

`问题背景 -> 方法/方案概述 -> 实施细节 -> 量化效果 -> 个人贡献`

结合当前资料，建议优先展示：

1. 复合机器人 OCS2 全身协同控制（移动底盘 + 腰部 + 双臂）
2. 基于 PPO 的智能力控（Isaac Gym + 力位混合控制）
3. 固定时间观测 + 结构化深度神经反步姿态控制
4. 神经网络 + 双通道事件触发姿态控制（含通信降频结果）

### 5) Experience（经历）

- 实习/研究经历按时间倒序
- 每段经历突出职责与结果，不写流水账

### 6) Publications / Patents（可选）

- 若有论文、专利、技术报告可单独成页
- 建议区分「已发表 / 在投 / 进行中」

### 7) Awards（荣誉）

- 精简到 3-6 条高价值荣誉即可

### 8) Contact（联系）

- 邮箱（建议公开邮箱）
- GitHub
- 其他可选方式（如 LinkedIn/微信）

---

## 展示风格建议

- 页面风格：简洁、技术感、突出结果数据
- 文案风格：动词开头 + 技术关键词 + 量化指标
- 项目配图：优先放系统框图、仿真截图、控制效果曲线

---

## 内容组织建议（适配你当前经历）

- 主线定位：机器人运动控制 + 强化学习 + 具身智能执行层
- 关键词池：`ROS2` `MPC` `WBC` `PPO` `Isaac Gym` `Gazebo` `sim2real` `力位混合控制` `鲁棒性` `固定时间收敛`
- 叙事方式：从「理论可证」到「工程可复现」再到「落地可部署」

---

## GitHub 实施建议

- 建议技术栈：`GitHub Pages + Hugo` 或 `GitHub Pages + Jekyll`
- 建议目录：
  - `about/`
  - `projects/`
  - `publications/`（可选）
  - `assets/`
  - `resume.pdf`
- 建议增加中英文切换（面向国际团队时加分）

---

## 下一步可执行清单

1. 确定站点结构（单页 or 多页）
2. 从当前简历抽取项目卡片（每个项目 80-120 字摘要）
3. 准备 3-6 张高质量项目配图
4. 完成首页 + 项目页初稿
5. 上线 GitHub Pages 并绑定自定义域名（可选）
